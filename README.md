# Jueves FC

MVP para organizar los partidos de futbol de los jueves.

## Funciones

- Gestionar jugadores con puntaje de 1 a 5 y posiciones.
- Crear partido con fecha, cancha y formato.
- Seleccionar jugadores disponibles.
- Sortear equipos balanceando puntaje y posiciones.
- Guardar resultado.
- Ver ranking acumulado.

## Ejecutar

Abre `index.html` en el navegador o levanta el servidor local:

```bash
node server.mjs
```

Luego entra a `http://localhost:5173`.
